# ADR-0011: Competitor-Pattern Evidence and Deferred External User Testing

- **Status:** Accepted
- **Date:** 2026-08-19

## Context

The founders want to reach a build-ready project plan quickly and do not want interviews, surveys, or usability sessions to become procedural gates. Several direct and adjacent products already expose relevant gym-discovery, filter, map/list, profile, booking, and trust patterns.

## Decision

1. External user interviews, surveys, and usability tests are deferred until a prototype or functional alpha unless a founder explicitly reopens a specific research question.
2. Pre-implementation UX decisions will use founder requirements, competitor-pattern analysis, accessibility heuristics, data feasibility, and technical constraints.
3. Comparable products are pattern evidence only. The project may adapt interaction principles, information hierarchy, filter structures, state handling, and trust presentation.
4. The project must not copy proprietary branding, logos, illustrations, marketing copy, user content, or a complete screen composition.
5. The planning package must state which assumptions remain unvalidated by real usage.

## Consequences

- External user testing is not part of the planning-readiness gate.
- The project accepts a higher risk that some UX or demand assumptions will need revision after alpha usage.
- The pilot measurement plan must capture search failures, comparison usage, profile views, correction behavior, and other real product evidence.
- A later targeted usability test may be added when a concrete ambiguity cannot be resolved through product evidence or accessibility review.
