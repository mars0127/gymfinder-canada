# ADR-0002: Serve Strength-Training Users First

- **Status:** Provisional
- **Date:** 2026-08-19

## Context

General gym users often choose primarily by distance, price, hours, and basic amenities already available through existing sources. Strength-training users more frequently care about exact machine types, rack/platform availability, loading type, manufacturer, and maximum dumbbell weight.

## Decision

Use bodybuilders, powerlifters, hypertrophy-focused lifters, and serious recreational strength trainees as the provisional first segment.

## Alternatives considered

- All gym users.
- Boutique class users.
- Personal-training clients.
- Accessibility-first niche.

## Consequences

- Equipment taxonomy becomes central.
- The initial market is narrower but the value proposition is more differentiated.
- The schema should remain extensible to broader users.

## Validation

Retain this decision when task evidence shows that exact equipment or facility attributes materially change gym choices. Reconsider when distance and price dominate nearly every tested decision.
