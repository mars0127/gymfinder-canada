# Research Workspace

Commit only sanitized research outputs.

Recommended structure:

```text
research/
├── audits/          # Gym profile audits without private personal data
├── task-tests/      # Participant-coded task observations
└── summaries/       # Decision-linked synthesis
```

Do not commit:

- participant names or contact information;
- precise home locations;
- raw recordings;
- private gym correspondence;
- restricted copied platform content;
- unlicensed images;
- secrets or credentials.

Use the templates under `docs/templates/` and link each output to a GitHub issue.
