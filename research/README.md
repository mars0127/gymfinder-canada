# Research and Planning-Evidence Workspace

Commit only sanitized, decision-linked outputs.

Recommended structure:

```text
research/
├── audits/                  # Five-gym data-calibration records and source comparisons
├── competitor-patterns/     # Sanitized UX pattern observations
├── summaries/               # Decision-linked synthesis and recommendations
└── task-tests/              # Deferred prototype/alpha tests if later authorized
```

Do not commit:

- participant names or contact information;
- precise private locations;
- raw recordings;
- private gym correspondence;
- restricted copied platform content;
- unlicensed images;
- secrets or credentials.

Use the templates under `docs/templates/` and link each output to the issue it informs. External user testing is deferred until prototype or alpha unless a founder explicitly reopens a named decision.
